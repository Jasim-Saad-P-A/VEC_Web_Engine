# VEC Web Engine

A web-based platform developed for managing and delivering digital
content and services for VEC.

## 👨‍💻 My Contribution

I contributed extensively to the **frontend development and debugging
of the administrative features** of the VEC Web Engine.

### 🛠️ Admin Features

Developed and debugged administrative interfaces for:

- 🏛️ Principal management
- 👨‍🏫 Head of Department management
- 💡 IIC (Institution's Innovation Council)
- 📅 Events management
- 📜 Certificates management
- 📋 Policies management
- 📰 Institutional content management

### 💻 Frontend Development

- Developed React-based administrative interfaces
- Built and refined reusable UI components
- Implemented responsive layouts
- Worked on page routing and navigation
- Integrated frontend interfaces with backend APIs
- Handled dynamic content and data rendering
- Worked with image and media management
- Implemented frontend forms and administrative workflows

### 🐛 Debugging & Problem Solving

A significant part of my contribution involved **debugging and

- Investigating frontend runtime errors
- Debugging API integration issues
- Fixing data rendering problems
- Resolving image and media path issues
- Debugging state and form-related issues
- Fixing routing and navigation problems
- Testing administrative workflows
- Improving UI consistency and responsiveness
